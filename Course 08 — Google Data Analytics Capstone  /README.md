## 📌 Course Overview

Course 08 is the Capstone of the Google Data Analytics Professional Certificate.  
This course brings together all previously learned skills and applies them to a real-world business case study.

The Capstone marks the transition from **learning analytics concepts** to **demonstrating professional competence**.

This project simulates the real responsibilities of a junior data analyst and results in a portfolio-ready case study.

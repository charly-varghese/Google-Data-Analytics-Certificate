# 📊 Course 07 — Data Analysis with R Programming  
**Google Data Analytics Professional Certificate**

---

## 📌 Course Overview

Course 07 focuses on performing data analysis using R programming.  
This course builds hands-on expertise in:

- Writing R scripts
- Cleaning and transforming data
- Creating visualizations using ggplot2
- Documenting analysis with R Markdown
- Producing reproducible reports

This course bridges the gap between foundational analytics and professional-level data analysis workflows.

---

## 🧠 Skills Gained

- R programming fundamentals
- Data manipulation using `dplyr`
- Data tidying using `tidyr`
- Data visualization using `ggplot2`
- Handling missing values & outliers
- Using smoothing techniques (loess, GAM)
- Facets & grouped visualizations
- Overplotting solutions (`alpha`, `geom_jitter`)
- Saving plots using `ggsave()`
- Creating reproducible reports using R Markdown

### 🔹 Module 01 — Introduction to R & RStudio
- RStudio interface understanding

### 🔹 Module 02 — Programming Using RStudio
- Vectors & data structures
- Conditional statements
- Functions
- Basic debugging

### 🔹 Module 03 — Working with Data in R
- Data frames vs tibbles
- Importing data (`readr`, `readxl`)

- IQR & outlier detection

- Smoothing (`geom_smooth()`)
- Handling overplotting
- Filtering before plotting
- Labels & annotations
- Saving plots (PNG, PDF, DPI control)

### 🔹 Module 05 — R Markdown & Reporting
- YAML header structure
- Code chunks & chunk options
- Inline code
- Markdown formatting
- Exporting reports (HTML, PDF, Word)
- Reproducible analysis workflows

# 📜 Certificates – Google Data Analytics Professional Certificate

---

## 🎯 Overview

This folder contains **verified course completion certificates** from the  
**Google Data Analytics Professional Certificate** program offered through **Coursera**.

Each certificate corresponds to a completed course and validates the knowledge, skills, and professional competencies documented in the respective course folders of this repository.

---

## 🧩 Certificates Included (Courses 01–05)

- **Foundations: Data, Data, Everywhere**  
  *Introduces data analytics concepts and analytical thinking foundations.*

- **Ask Questions to Make Data-Driven Decisions**  
  *Focuses on structured questioning, stakeholder communication, and decision-making using data.*

- **Prepare Data for Exploration**  
  *Covers data credibility, ethics, data types, metadata, databases, and data organization.*

- **Process Data from Dirty to Clean**  
  *Demonstrates practical data cleaning, validation, documentation, and ethical handling.*

- **Analyze Data to Answer Questions**  
  *Applies spreadsheets and SQL to transform prepared data into decision-ready insights.*

Each certificate is provided in **PDF format** for authenticity and verification.

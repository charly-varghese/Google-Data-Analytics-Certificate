## 🧹 Course 04 – Process Data from Dirty to Clean 
## (Google Data Analytics Professional Certificate)

### 🎯 Course Purpose

This course trains a data analyst to identify, clean, validate, verify, and document data so that it becomes accurate, reliable, ethical, and ready for analysis.
Process Data from Dirty to Clean bridges the gap between raw data and trustworthy insights, forming one of the core professional responsibilities of a real-world data analyst.

### 🧠 What This Course Trains You to Do

 ### By completing this course, you learn to:
- **Diagnose common data quality and integrity issues** 
- **Clean and transform data using spreadsheets and SQL** 
- **Handle duplicates, missing values, and inconsistent formats** 
- **Verify that cleaning steps were applied correctly** 
- **Document all cleaning decisions transparently**  
- **Apply ethical thinking and bias awareness during data preparation**

# 📊 Course 05 – Analyze Data to Answer Questions  
### Google Data Analytics Professional Certificate

---

## 🎯 Course Purpose

This course focuses on transforming prepared data into **clear, validated answers** using spreadsheets and SQL.  
It trains analysts to organize, calculate, aggregate, and summarize data so that insights can be confidently shared with stakeholders for **data-driven decision-making**.

---

## 🧠 What This Course Trains You to Do

By completing this course, you learn to:

- Organize and prepare data for analysis  
- Perform calculations using spreadsheets and SQL  
- Combine data from multiple data sources  
- Summarize and validate data to answer business questions  
- Communicate analytical findings clearly to stakeholders  

---

## 🧩 Key Topics Covered

### 🔹 Organize Data for Analysis

- Sorting and filtering data without modifying raw datasets  
- Formatting data:
  - Dates  
  - Currency  
  - Percentages  
  - Text cleanup using TRIM and VALUE  
- Data validation:
  - Accuracy checks  
  - Consistency checks  
  - Range and type validation  
- Absolute and relative cell references in formulas  
- Preparing clean, structured data for analysis  

---

### 🔹 Perform Calculations in Spreadsheets

- Core spreadsheet functions:
  - SUM  
  - AVERAGE  
  - COUNT  
- Conditional calculations:
  - SUMIF / COUNTIF  
  - SUMIFS / COUNTIFS  
- Advanced spreadsheet logic:
  - ARRAYS  
  - SUMPRODUCT  
  - VALUE (text-to-number conversion)  
  - MOD (%) for classification logic  

---

### 🔹 Pivot Tables and Data Summarization

- Creating pivot tables from large datasets  
- Using pivot table components:
  - Rows  
  - Columns  
  - Values  
  - Filters  
- Calculated fields  
- Sorting and filtering pivot results  
- Summarizing data without altering source datasets  

---

### 🔹 Analyze Data Using SQL

- Core SQL commands:
  - SELECT  
  - WHERE  
  - ORDER BY  
  - LIMIT  
- Aggregation and grouping:
  - GROUP BY  
  - COUNT  
  - COUNT DISTINCT  
  - SUM  
  - AVG  
  - MIN / MAX  
- Aliasing using `AS` for readability  

---

### 🔹 SQL Joins and Subqueries

- JOIN types:
  - INNER JOIN  
  - LEFT JOIN  
  - RIGHT JOIN  
  - FULL OUTER JOIN  
- Combining data from multiple tables  
- Subqueries:
  - Subqueries in SELECT  
  - Subqueries in FROM  
  - Subqueries in WHERE  
- Using subqueries for:
  - Filtering  
  - Ranking  
  - Derived metrics  

---

### 🔹 Advanced Analysis and Temporary Structures

- SQL calculations:
  - Arithmetic operations  
  - Percent and ratio calculations  
  - ROUND for numeric precision  
- Handling division-by-zero safely  
- Temporary tables and CTEs:
  - WITH clause  
  - SELECT INTO (database-dependent)  
- Data staging and performance optimization  

---

### 🔹 Hybrid Analysis Tools

- Connected Sheets with BigQuery  
- Analyzing large datasets through spreadsheet interfaces  
- Secure collaboration using a single source of truth  
- Pivot tables and charts on live database data

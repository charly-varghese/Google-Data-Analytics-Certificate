🎯 Course 02-Ask Questions to Make Data-Driven Decisions: 
  (Google Data Analytics Professional Certificate)

🎯 Course Purpose

This course trains a data analyst to define the right problem before analyzing data.
It focuses on analytical thinking, structured questioning, and professional communication with stakeholders to ensure that analysis leads to meaningful, decision-ready insights.
Course 02 bridges foundational analytics knowledge with real-world business decision-making.

🧠 What This Course Trains You to Do

By completing this course, you learn to:
Ask effective, structured, and unbiased questions
Translate vague business requests into clear analytical objectives
Apply data-driven decision-making frameworks
Use spreadsheets as a foundational analytical thinking tool
Communicate insights clearly to stakeholders
Manage expectations, scope, and timelines professionally

🧩 Key Topics Covered

🔹 Asking Effective Questions
Problem vs symptom identification
SMART questions (Specific, Measurable, Action-oriented, Relevant, Time-bound)
Open-ended vs closed-ended questions
Avoiding assumptions and confirmation bias
Framing questions that guide meaningful analysis

🔹 Data-Driven Decision Making

Data-driven vs intuition-driven decisions
Qualitative vs quantitative data
Primary vs secondary data
Biased vs unbiased data
Using data to support recommendations

🔹 Spreadsheets as an Analytical Tool

Why spreadsheets matter in analytics
Structured thinking using rows, columns, and schemas
Data organization best practices
Metadata awareness
Preparing data for analysis
These concepts form the foundation for later work in SQL, databases, and BI tools.

🔹 Stakeholder Management

Identifying primary and secondary stakeholders
Understanding stakeholder needs and expectations
Communicating analysis clearly and transparently
Running effective meetings (before, during, after)
Managing disagreements and scope using data

🛠 Skills Developed

Structured analytical thinking
Data literacy
Stakeholder communication
Data-driven decision support
Spreadsheet-based analysis
Problem framing and clarification
Bias awareness and ethical questioning

🔧 Tools Introduced

Google Sheets
Spreadsheet logic transferable to Excel and SQL
Conceptual awareness of databases and SQL

🧠 Professional Insight

Data analysts do not make business decisions —
they enable better decisions by providing clarity, evidence, and context.
This course reinforces that:
Analysis starts with questions, not tools
Poor questions lead to poor insights, regardless of data quality
Stakeholder trust is as important as technical accuracy

📌 Why This Course Matters
Course 02 ensures that analysts:
Solve the right problem, not just any problem
Align analysis with business objectives
Communicate insights in a way decision-makers understand
Avoid common beginner mistakes related to bias and misalignment
This course is a critical foundation for data preparation, cleaning, and analysis in later courses.
